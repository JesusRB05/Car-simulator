# AGENTS.md

Guide for agents working in this repository. Read it before touching code.

## Project

Driving simulator: in-house physics engine (rigid bodies, joints), Vulkan
rendering (small RHI + renderer), vehicle, interactive app (`apps/sim`) with
ImGui/ImPlot, modding and a plugin API. Project documentation lives in `docs/`;
code conventions are in `docs/CONVENTIONS.md`.

## Language

- **Everything is written in English**: documentation, code comments,
  identifiers, log/UI messages and commit messages.

## Essential conventions

- SI units, radians, seconds, metres. Right-handed world with `-Z` forward,
  `+Y` up, `+X` right, with no exceptions (the vehicle included: heading 0
  faces `-Z`).
- **Column-major** matrices in GLM and **`column_major`** + `mul(M, v)` in
  Slang; uploaded verbatim with `writeMatrix()`, never transposed.
- Reversed-Z depth: `GreaterEqual`, cleared to `0.0f`.
- Double-precision physics, fixed step, deterministic, `/fp:precise`, no
  `-ffast-math`. Do not introduce `float` or a variable `dt` in the engine.
- C++17+, SPDX GPL-3.0-or-later in every file, `clang-format`.

## Build

Windows builds use the CMake presets (MSVC + Ninja). `cmake`, `cl`, `ninja` and
`ctest` are usually not on the `PATH`; open a developer environment first.

- **Visual Studio 2022 or later** (Build Tools are enough) with the
  "MSVC x64/x86 build tools" component. Locate it with `vswhere` instead of
  hardcoding an edition or version path, then call
  `VC\Auxiliary\Build\vcvars64.bat` from that installation.
  `tools\dev-env.bat` does exactly this.
- **vcpkg**: set the `VCPKG_ROOT` environment variable to a stable clone (for
  example `C:\dev\vcpkg`, never a temporary folder). All presets take the
  toolchain from `$env{VCPKG_ROOT}` and run in manifest mode; `vcpkg.json` pins
  the `builtin-baseline`, so everyone gets the same dependency versions.
- **slangc**: if it is not on the `PATH`, CMake downloads a prebuilt Slang.
  To use a local copy, pass the `SIM_SLANGC` cache variable
  (`-DSIM_SLANGC=...\slangc.exe`) or set the `SIM_SLANGC` environment variable.
- **Non-English MSVC**: install the English language pack. The Windows presets
  set `VSLANG=1033`; without the English pack `cl /showIncludes` prints
  localized prefixes and Ninja silently loses header dependencies.

```bat
for /f "usebackq delims=" %%i in (`"%ProgramFiles(x86)%\Microsoft Visual Studio\Installer\vswhere.exe" -latest -prerelease -products * -requires Microsoft.VisualStudio.Component.VC.Tools.x86.x64 -property installationPath`) do set "VSINSTALL=%%i"
call "%VSINSTALL%\VC\Auxiliary\Build\vcvars64.bat"
rem or simply: call tools\dev-env.bat
set "VCPKG_ROOT=C:\dev\vcpkg"
cmake --preset windows-msvc-release
cmake --build --preset windows-msvc-release --target sim       # app
cmake --build --preset windows-msvc-release --target sim_tests # suite
```

(Inside an interactive `cmd` prompt, write `%i` instead of `%%i`.)

## Tests

- CPU tests (physics, core, modding and render math):
  `build\windows-msvc-release\bin\sim_tests.exe` or
  `ctest --test-dir build\windows-msvc-release -R sim_tests -V`.
- GPU tests (headless, require a Vulkan ICD + `-DSIM_ENABLE_GPU_TESTS=ON`):
  with Mesa lavapipe, run from the repository root
  `set "VK_ICD_FILENAMES=%CD%\tools\mesa\x64\lvp_icd.x86_64.json"`
  and add `tools\mesa\x64` to `PATH`; then
  `ctest --test-dir build\windows-msvc-release -L gpu --output-on-failure`.
- Golden images: candidates are regenerated by hand with
  `cmake --build <build> --target update_golden` (they are written to
  `screenshots/golden_candidates/`) after intentional changes, never to paper
  over a regression. They move to `tests/golden/<driver>/` only after human
  approval; while they do not exist, the GPU verification tests are reported
  as skipped (`SKIP_RETURN_CODE 77`). Comparison uses realistic tolerances
  (at most 1 % differing pixels, PSNR ≥ 30 dB).

## Git

- Logical commits, Conventional Commits messages in English, and **all of them
  signed off with the DCO** (`git commit -s`); see `docs/CONTRIBUTING.md`.
- Do not push automatically if there are no credentials; the `origin` remote
  may be a placeholder.
